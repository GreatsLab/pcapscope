pcapscope

See what's in a packet capture without opening Wireshark.

Drop a .pcap or .pcapng file anywhere on this page. You get the protocols, who talked to whom, every DNS lookup, the TLS server names, HTTP requests, and a list of things that look wrong: credentials in clear text, port scans, ARP spoofing, DNS tunnelling.

Parsed entirely in your browser. The file never leaves your machine.
